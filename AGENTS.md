# Entrada de desenvolvimento de sites

Para pedidos de criar, melhorar ou clonar site neste projeto, antes de executar siga a skill site-intake: faca perguntas progressivas, exija referencia visual aceita e confirme lacunas antes da parte afetada. Nao aplique a tarefas de documentacao isoladas.

Leia .agents/skills/site-intake/SKILL.md e use as informações já fornecidas sem repetir perguntas. As regras são instruções para o agente; não garantem bloqueio técnico.
